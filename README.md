# 粒子爱心 · 心跳

一个会心跳的 3D 粒子爱心，纯前端单文件实现，零依赖、零构建、零 CDN。

红底之上，一万四千条白色粒子刺从心形表面向外生长，随心跳节拍集体收缩与膨胀，像一颗正在跳动的心脏。

## 如何使用

四种方式，按需选一种。

### 一、直接在线打开

访问 <https://2362157554-ux.github.io/heart-particles/>

不用下载、不用安装，打开就能看。适合分享给别人，手机浏览器也能开。

### 二、克隆到本地

```bash
git clone https://github.com/2362157554-ux/heart-particles.git
cd heart-particles
```

然后双击 `index.html`，用浏览器打开即可。不需要安装依赖，不需要启动服务器，不需要联网。

### 三、只取单个文件

整个效果全部在 `index.html` 一个文件里，不含任何外部资源引用。下载这一个文件，丢进任意目录或静态托管都能直接用。

想嵌到自己网页里，用 iframe 即可：

```html
<iframe src="index.html" style="width:100%;height:100vh;border:0"></iframe>
```

### 四、下载 ZIP

在仓库页面点绿色的 **Code** 按钮，选 **Download ZIP**，解压后打开 `index.html`。

## 如何改

打开 `index.html`，文件顶部有一个 `CONFIG` 对象，所有手感参数都集中在那里，改完保存、刷新页面即可生效。常用项见下方参数表。

## 交互

拖动旋转 · 滚轮缩放。松手后自动旋转会恢复。

## 实现说明

整份代码只有一个 HTML 文件，没有任何外部资源引用。

心形轮廓用经典参数方程生成，再沿射线方向向内收缩采样，形成实心区域；上下两个壳面按 `sqrt(1 - r²)` 起伏，让心"鼓"起来，而不是一张薄片。

每颗粒子是一条从心点指向刺尖的白色细线，刺长随机。每次心跳的强度由一条 3D 值噪声驱动，噪声只看粒子的空间位置和一个随时间流动的相位，所以整颗心是"一起呼吸"的，而不是每个粒子各自随机抖动。

深度感来自三个技巧：远侧粒子先以极低透明度铺底；心形本体随后用背景色填充，把远侧粒子盖住，于是近侧粒子自然显得浮起；近侧粒子再按深度分成三档亮度与线宽分别绘制。

渲染使用 Canvas 2D。为了在低端设备上不卡，主循环会统计帧间隔，连续掉帧时自动降低参与绘制的粒子比例。

## 可调参数

文件顶部 `CONFIG` 集中了所有手感参数：

| 参数 | 含义 | 默认 |
| --- | --- | --- |
| `spikes` | 粒子刺数量，越大越浓密 | 14000 |
| `puff` | 心形饱满度，0 是薄片 | 0.42 |
| `spikeMin` / `spikeMax` | 刺长范围 | 0.012 / 0.070 |
| `spikeBase` | 脉动基准缩放，心跳最弱时的基准尺寸 | 1.03 |
| `spikeAmp` | 脉动幅度系数，越大起伏越剧烈 | 0.115 |
| `noiseScale` | 噪声坐标缩放，越大表面波纹越细碎 | 2.40 |
| `distance` | 相机距离，越大心越小 | 3.00 |
| `spin` | 自动旋转速度 | 0.22 |
| `waveSpeed` | 心跳波纹流动速度 | 0.85 |
| `beatRise` / `beatFall` / `beatRest` | 心跳的收缩、回弹、停顿时长 | 0.36 / 0.92 / 0.60 |
| `beatPeak` | 心跳峰值强度 | 1.45 |
| `bg` | 背景色，同时是心形本体色 | `#e01f3d` |

心跳节奏为急收缩、慢回弹、稍长停顿，比常见的匀速脉动更接近真实心跳。改 `bg` 可以整体换色，比如换成 `#0b0b12` 就是黑底星云感。

## 兼容性

现代桌面与移动浏览器均可。移动端会自动降低粒子数量。
